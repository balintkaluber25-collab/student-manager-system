# Student Management System

A command-line Student Management System built with Python using Object-Oriented Programming (OOP).

The application allows users to manage student records, track grades, calculate averages, and store data between sessions using JSON persistence.

## Features

- Add and remove students
- Search for students by ID
- List all registered students
- Add grades to students
- Calculate individual and class averages
- Identify the top-performing student(s)
- Find students who received a specific grade
- Automatically save and load student data using JSON

## Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- JSON for data persistence
- Git and GitHub

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/balintkaluber25-collab/student-manager-system.git
```

2. Navigate to the project directory:

```bash
cd student-manager-system
```

3. Run the application:

```bash
python3 main.py
```
